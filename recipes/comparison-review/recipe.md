# Comparison Review

Installs one Comparison Finding convention and an operating reference. Installation creates no
findings, Artifacts, source bindings or running tools. Use the existing Artifact command to retain
selected HTML, then ordinary Kind-aware document commands to record a comparison and its decision.

The examples at `examples/comparison-review` demonstrate camera and benchmark consumers. Existing
source observations, Signals and named-human Review Requests retain their own responsibilities.
