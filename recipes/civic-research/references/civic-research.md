# Civic research and editorial handoff

Capture exact evidence, record source assertions, propose scoped identities/connections, review, then
select useful resident-facing leads through the existing publisher. Those are separate effects.
The base owns source/record/text/evidence schemas; this add-on owns matters/observations/connections.
Provider adapters own discovery/capture. The publisher owns freshness, privacy and editorial release.

The base's legacy Civic Finding remains compatible and can hold resident relevance and verification
needs. This add-on neither redeclares it nor moves its recipe ownership. A future clean split into a
publication-specific recipe needs an explicit migration/ownership plan, not copy/paste inheritance.

Installation is inert. It never generates AI insights or infers relationships. Native Kind checks
validate shapes, enum/date values and declared links; they cannot prove a citation supports a claim.
Use separate reviewed source/connection evidence and negative controls. A reviewed connection is
not an automatic H&M contribution or public fact. Unknown dates stay absent, unresolved assertions
remain distinct, agendas do not establish votes, and an appropriation does not prove final cost.

Caller-declared public recipe-set preflight can check the finite selected base/add-on/consumer
structure before installation. It does not discover every consumer, authorize hosted access or
create dependencies. Install explicitly, then inspect native recipe evolve plans for additive changes. Convention stamps are last-writer
provenance, not a universal cross-recipe ownership barrier: additive same-Kind evolution can
transfer a foreign stamp. This add-on avoids that coupling by declaring only disjoint new Kinds.
Caller structural preflight reports local adaptation/foreign snapshots before this workflow proceeds;
that read-only report is not an authorization lock against other writers.
